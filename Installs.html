使用启动器或手动安装 Reimagined

 

Reimagined 启动器（非常简单）在 Windows 上安装并自动更新，可在 Nexus Mods 获取。  一键即可在线查找 Reimagined 的最新版本，并自动备份你的存档。

 

Beta 启动器（简单）：是一个批处理文件，本指南下方配有图示说明。  同样会自动备份你的存档。 

 

手动按步骤操作（简单/困难）：你需要自行查找安装目录，并自行负责备份存档，以防加载画面中发生崩溃。

 

默认文件位置——取决于你是在 Battle.net 客户端还是 Steam 购买

C盘是最常见的安装位置。你的实际位置可能因个人设置不同而有所差异。  启动器会自动查找这些位置。

Battle.net D2R 模组文件： C:\Program Files (x86)\Diablo II Resurrected\mods\Reimagined

Steam D2R 模组文件： C:\Program Files (x86)\Steam\steamapps\common\Diablo II Resurrected\mods\Reimagined

存档文件： C:\Users\%USERPROFILE%\Saved Games\Diablo II Resurrected\mods\ReimaginedThree

 

手动创建存档备份

1. 在文件资源管理器中，前往上方列出的存档文件目录。

2. 返回上一级目录，进入 \Saved Games\Diablo II Resurrected\mods\ 文件夹，其中包含各个模组各自的存档，如下图所示。

所有 Reimagined 3.x 版本的存档都位于 ReimaginedThree 文件夹中。

3. 如图所示，右键点击  ReimaginedThree 文件夹，选择“发送到”，再选择 压缩(zipped)文件夹，即可将内容复制为一个 ZIP 文件。将该 ZIP 文件重命名为便于记忆的名称，并移动到容易找到的位置（例如桌面）。

记得定期创建新的 ZIP 存档备份，以免在发生崩溃时丢失进度。  游玩过程中，如果电脑在游戏正在写入存档时崩溃，该存档可能会损坏，导致出现“加入游戏失败”的提示。  Reimagined 启动器可以自动备份你的存档，让这项工作更加轻松。

频繁崩溃？故障排除小贴士

以下是我们在 Discord、Nexus 和 Reddit 的问题反馈中，针对频繁崩溃问题总结出的一些常见解决办法。

1. Reimagined 3.0+ 与 Reimagined 1.x.x、Reimagined 2.x.x、D2R 原版或其他模组的存档不兼容（如果存档中包含物品的话）。尝试将它们放入存档文件夹并使用，往往会导致游戏崩溃。

2. 无法创建经典模式角色，且经典模式与本模组不兼容。

3. 将画质选项中的“VFX灯光质量”从“极高”改为“高”或“中”，这几乎不会影响视觉效果，但会显著拖累游戏性能并导致崩溃。

4. 将帧率上限设置为你显示器的刷新率，和/或开启垂直同步（Vsync）。

5. 不要按 Alt+Tab 切出游戏，（如果是窗口模式游玩，可以点击屏幕外）游戏不喜欢失去焦点。你可以尝试通过显卡控制面板限制 D2R.exe 的后台帧率来缓解此类崩溃。（游戏仍然可能崩溃，但限制后台帧率有助于降低崩溃频率。）

6. 不要给佣兵装备带有“几率触发召唤类技能”的物品。（复生（Reanimate）没问题，主要是 CTC 类型的召唤技能会导致问题。）

7. 将电源设置从“性能模式”改为“平衡模式”（听起来有点反直觉，但对一部分人确实有效。）

8. 如果你还在使用其他模组，可以尝试先禁用它们，看崩溃是否仍然发生；但如果这些模组修改了 itemstatcost.txt，禁用它们后仍然可能导致崩溃，所以请留意自己在做什么，并在实验前做好备份。

9. 如果你自己进行了本地模组修改，请撤销这些修改或重新全新安装模组。

 

D2RMM

使用模组管理器可以让你轻松地同时安装多个模组（前提是它们彼此兼容），而无需了解任何模组制作相关知识。

Reimagined 本身已经包含了大量丰富的功能和生活质量改进，因此并不总是需要额外安装其他模组。 

请查看 Reimagined 功能列表，看看某个第三方模组是否仍有必要安装。

 

使用 D2RMM 时，你的实际生效模组文件将位于 D2RMM\mods\ 文件夹下，而不是 Diablo II Resurrected\mods\。

你对 Reimagined 文件所做的任何修改都需要在 D2RMM 的 mods 目录中进行。

如果你正在使用（上文提到的）BETA 启动器，你需要将文件改动从 Diablo II Resurrected\mods\Reimagined\Reimagined.mpq\ 复制到 D2RMM\mods\Reimagined\。
 

文件操作步骤

1. 从 D2RMM Github 下载 D2RMM。

2. 打开 D2RMM 文件夹——进入 mods 目录。

  • 你应该会看到一个名为 “PUT YOUR MODS HERE” 的文本文件——先不要关闭这个窗口，稍后会用到。

3. 打开一个新的文件资源管理器窗口，前往你 D2R 安装目录下的 Reimagined 模组文件夹。

4. 复制 Reimagined.mpq 文件夹（其中应包含一个 Data 文件夹和 ModInfo.json）。

5. 将 Reimagined.mpq 文件夹粘贴到第2步中的 D2RMM/mods 文件夹内。

  • 我们建议将该文件夹重命名为 Reimagined

D2RMM 操作步骤

6. 以管理员身份打开 D2RMM。

7. 打开后，点击右下角的三个点，选择“Refresh Mod List（刷新模组列表）”。

8. Reimagined 应该会出现在模组列表中——点击左侧的复选框以启用它。

Reimagined 文件夹必须始终位于模组列表的最上方。如果不是，请点击并拖动该行到最上面。

9. 前往（顶部的）Settings（设置）标签页。

  • 9a. 点击 General（常规）。
    • 将“Output Mod Name（输出模组名称）”改为“Reimagined”。
    • 开启“Automatically install mods before running the game（运行游戏前自动安装模组）”。
  • 9b. 点击 Game Launcher（游戏启动器）。
    • 在“Extra Game Args（额外游戏参数）”下，粘贴以下内容：-mod Reimagined -txt
    • 如果你还想添加其他参数，可以在其后自行追加。

10. 返回 Mods（模组）标签页。

11. 点击 Install Mods（安装模组）。
 

开始游玩！

12. 点击 'Run D2R'。
 

掉落过滤器

本指南假设你已经下载并安装了 D2RMM（见上文）

  • 由于术士 DLC 的存在，我们建议直接使用游戏内置的掉落过滤系统，它与我们的宝物文件、字符串以及模组新增物品都是兼容的。
  • 对于没有该 DLC 的用户，下方的过滤器以及 Nexus 上其他类似过滤器均需自行承担使用风险，Reimagined 并不提供支持。本模组会修改这些过滤器所涉及的每一个文件，作者需要专门为 Reimagined 制作对应版本，才能保证完全兼容、不出问题。
     

文件操作步骤

1. 从 Nexus Mods 下载 Pseudo Loot Filter。

  • 选择“Mod manager download（模组管理器下载）”可自动下载并将模组载入 D2RMM。
  • 选择“Manual download（手动下载）”可将模组下载到你的 下载 文件夹——然后将模组解压到你的 D2RMM/mods 文件夹中。
     

D2RMM 操作步骤

2. 在 D2RMM 中，点击右下角的3个点，选择“Refresh Mod List（刷新模组列表）”。

3. 此时你应该能在模组列表中看到 Pseudo Loot Filter——点击左侧的复选框以启用该模组。

4. 要配置该掉落过滤器，点击右侧的“settings（设置）”。

5. 所有物品默认均为启用状态（滑块位于右侧）——点击滑块即可禁用该物品（此操作会影响所有稀有度，包括白色、蓝色、黄色、套装、暗金）。

  • 禁用某个物品，意味着当该物品原本会掉落时，游戏会改为不掉落任何东西。
  • 禁用某些物品不会影响其他物品的掉落几率。
  • 可能需要多刷几次才能把这份列表调整到你满意的状态。

6. 完成禁用不想要的物品后，点击关闭菜单。

7. 点击右下角的“Install Mods（安装模组）”。

8. 点击“Run D2R”。

Reimagined 与 D2RLoader

D2RLoader 为 Reimagined 提供了 局域网 TCP/IP 联机支持，包括 术士降临（ROTW）内容，且不再有此前的职业与机制限制。

提示： D2RLoader 仍处于积极开发阶段，因此安装步骤和配置选项在未来的更新中可能会发生变化。

开始之前： 所有加入同一 TCP/IP 联机游戏的玩家，都必须使用完全相同版本的 D2R、D2RLoader 以及 Reimagined 兼容构建版本。

1. 安装 Reimagined 兼容构建版本

从 Google Drive 下载 Reimagined 兼容构建版本。

重要提示： Nexus 上的官方 Reimagined 正式版与 D2RLoader 不直接兼容。请使用上方链接提供的兼容构建版本。

下载并解压该压缩包，然后将解压出的 Reimagined 文件夹放入：

Diablo II Resurrected\mods

2. 安装并配置 D2RLoader

打开 D2RLoader 链接，然后从项目的 Download（下载） 分类中下载最新版本。

解压该压缩包后，将 d2rloader 文件夹、D2RCore.dll 和 D2RLoader.exe 移动到包含 D2R.exe 的暗黑破坏神II：狱火重生安装文件夹中。

用文本编辑器打开 d2rloader\config\d2rloader.toml，将 Reimagined 设置为默认模组：

default_mod = "Reimagined"

按 Ctrl+S 保存文件，关闭编辑器，然后运行 D2RLoader.exe 启动游戏。

3. 设置 Radmin VPN 以进行局域网联机

游戏和加载器现已准备就绪。要在互联网上与好友进行 TCP/IP 联机，所有玩家都必须加入同一个虚拟局域网。

下载并安装 Radmin VPN，然后将其开启。

打开 Network（网络） 菜单。为你的队伍创建一个私有网络，或者选择 Join Network（加入网络） 来连接一个已有的网络。

公开网络示例

Network name: D2RR TCP/IPPassword:     DeckardLikesWine@69

输入相关信息后点击 Join（加入）。Radmin VPN 应该会显示该共享网络及其中已连接的玩家。

4. 在游戏内通过 TCP/IP 进行连接

在选择角色界面，点击底部中间的 TCP/IP。

  • host（房主）：点击 Host Game（创建游戏）。将你的 Radmin VPN IP 地址提供给其他玩家。
  • 加入：点击 Join Game（加入游戏），输入房主的 Radmin VPN IP 地址，然后点击 OK（确定）。

联机清单

  • 相同的 D2R 版本
  • 相同的 D2RLoader 版本与配置
  • 相同的 Reimagined 兼容构建版本
  • 相匹配的模组文件

版本或文件不匹配 可能导致连接失败、崩溃、画面缺失、技能异常，或其他意外行为。

 

Reimagined 与 D2RLaunch

由制作并维护 D2R 模组 ReMoDDeD 的 D2R Modding 团队开发的启动器 D2RLaunch，同样可以很好地配合 Reimagined 使用，安装完成后可用它来启动和游玩本模组。

它的功能非常丰富，且有详尽的官方文档说明，其中也附有 discord 链接，可获取启动器设置与故障排除方面的帮助，以及一段附带操作说明的YouTube视频。

该启动器原生支持多个模组下载列表，其中不少都非常有趣，值得一试。

使用 D2RLan 搭配旧版本的 D2R（2.4开发者构建版本），你可以通过 VPN 直接与好友建立连接进行联机。
